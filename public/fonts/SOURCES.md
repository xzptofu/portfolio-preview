# Typeface sources

The portfolio self-hosts unmodified Latin variable WOFF2 subsets supplied by Google Fonts.
Font files load from the portfolio's own origin. Chinese text uses the visitor's system fallback.

## Geist

- Project: https://vercel.com/font
- File: `geist-latin-variable.woff2`
- Download: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFU.woff2
- Weights: 100–900.
